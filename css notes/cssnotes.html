This is the notes of CSS

type of selector

  1. Basic selector 
    • element              name{}
    • class               .name{}
    • ID                  #name{}
    • univercel           *{}
    • Attribute           element[attribute value]{}
      1. element[attribute Name] - Selects elements that have the attribute,
                            no matter its value
      2. element[attr="value"] - Selects elements where the attribute exactly 
                            equals the value
      3. element[attr~="value"] - Selects if the attribute value contains value
                            as a whole word.
      4. element[attr^="value"] - Selects if the attribute value starts with the
                            given value.
      5. element[attr$="value"] - Selects if the attribute value ends with the
                            given value.
      6. element[attr*="value"] - Selects if the attribute value contains the
                            given value anywhere.
