Formet specifier

inroduser of formet specifier symbol is :

  1. :.2f 
    .2 → Show 2 digits after the decimal point. 
     f → Stands for fixed-point number (float).
    use 
    - print(f'value of PI = {pi:.2f}')
  2. :5d 
     5 → Minimum width of 5 characters. 
     d → Format as integer (decimal).
    use 
    - print('{0:5d}'.format(1)) 
     only works with variable like thing
